# QUAREP-LiMi WG10 — Raw Image Data in Light Microscopy

Figure code for the paper on a metrological definition of raw image data.

## Overview

- On-device, black-box processing has made "raw image data" ambiguous in light microscopy
- This work proposes a formal metrological framework for raw images
- A raw image is defined by its unaltered physical measurements that preserve core statistical properties, not by its file format
- "Rawness" rests on four metrological pillars:
  - Trueness
  - Pixel-to-pixel independence
  - Quantifiable uncertainty
  - Full metadata traceability (e.g., calibration parameters aligned with EMVA1288)
- Judicious, documented processing can preserve these attributes
- The paper systematically evaluates how deconvolution, denoising and stitching distort measurement accuracy
- It introduces a practical decision-making framework linking instrument manufacturers and end-users
- The framework balances hardware constraints against image quality and scientific reproducibility
- The definition applies to all quantitative biomedical imaging workflows, not just optical microscopy
